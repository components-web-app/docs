`cwa make:component` is an interactive CLI that scaffolds a CWA component. It creates the Vue display file and prints the PHP command to generate the matching API entity.

```bash
npx cwa make:component
```

If `@cwa/nuxt` is listed as a dependency in your project, you can also run:

```bash
cwa make:component
```

## Prompts

### Component name

A PascalCase identifier. This becomes the file name and directory name.

```
Component name (PascalCase, e.g. BlogPost): HeroBlock
```

Output path: `app/cwa/components/HeroBlock/HeroBlock.vue`

### Component type

Selects which built-in plugin to wire up:

| Choice | Plugin | Use when |
|--------|--------|----------|
| `Basic` | none | Plain data display |
| `File` | `withFile()` | Entity has `#[Uploadable]` (any uploadable file, incl. images) |
| `Collection` | `withCollection()` | Entity extends or wraps a collection |

### API behaviours

Three yes/no prompts that control flags passed to `make:api-component`:

| Prompt | Flag | What it adds |
|--------|------|-------------|
| `--timestamped` | `--timestamped` | `createdAt` / `modifiedAt` columns |
| `--publishable` | `--publishable` | Draft / publish lifecycle |
| `--uploadable` | `--uploadable` | File upload field (defaults to **yes** for the File type) |

## What gets generated

The Vue file is written to `app/cwa/components/<Name>/<Name>.vue`. The script block is pre-wired to `useCwaComponent` based on the chosen type:

::code-group

```vue [Basic]
<template>
  <!-- TODO: add your template -->
</template>

<script setup lang="ts">
import type { IriProp } from '#cwa/composables/cwa-resource'

const props = defineProps<IriProp>()
const { resource, exposeMeta } = useCwaComponent(props)
defineExpose(exposeMeta)
</script>
```

```vue [File]
<template>
  <!-- TODO: add your template -->
</template>

<script setup lang="ts">
import type { IriProp } from '#cwa/composables/cwa-resource'

const props = defineProps<IriProp>()
const { resource, exposeMeta, files } = useCwaComponent(props, [withFile()])
defineExpose(exposeMeta)
</script>
```

```vue [Collection]
<template>
  <!-- TODO: add your template -->
</template>

<script setup lang="ts">
import type { IriProp } from '#cwa/composables/cwa-resource'

const props = defineProps<IriProp>()
const { resource, exposeMeta, collectionItems, pageModel, totalPages, goToNextPage, goToPreviousPage, changePage, resolveResourceLink } =
  useCwaComponent(props, [withCollection()])
defineExpose(exposeMeta)
</script>
```

::

## Next steps printed after generation

After writing the file, the CLI prints the PHP command to create the API entity. Run it in your API project:

```bash
php bin/console make:api-component HeroBlock --timestamped --publishable
```

It also says to register the component type in `nuxt.config.ts` under `cwa.resources`. **That step is optional.** Every component in `app/cwa/components/` is discovered automatically and appears in the admin's "Add Component" dialog under a name derived from its directory (`HeroBlock` → "Hero Block"). Add an entry only to change that name or set a description, `instantAdd` or `defaultData`; see [Creating Components → nuxt.config Registration](/nuxt-module/building-your-ui/creating-components#part-3-nuxtconfig-registration-optional).

## What the CLI does not generate

- The admin editing tab (`admin/<Name>.vue`) — write this manually following the [Your First Component](/guides/your-first-component) guide
- A `nuxt.config` entry, which is optional
