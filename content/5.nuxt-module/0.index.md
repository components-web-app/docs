This section is for front-end developers. It covers `@cwa/nuxt`, the front-end half of a CWA site: the Vue files you write for layouts, page templates and components, the composables they use, and the admin panel the module adds. For the Symfony side, see the [API Bundle](/api). If you're new to CWA, start with [Core Concepts](/core-concepts).

`@cwa/nuxt` connects a [Nuxt](https://nuxt.com) application to the API. It resolves every URL to the right layout, page and components, keeps them in a reactive store, applies real-time updates through Mercure, and ships the sign-in pages and the inline admin. You own the Vue templates; CWA decides what data they receive and in what order they render.

Start with [Module Setup](/nuxt-module/module-setup) to install it.

::callout{icon="i-heroicons-folder"}
Paths in this section start at the project root of the components-web-app template. The Nuxt app is `app/` and its source directory is also `app/`, so CWA's Vue files are in `app/app/cwa/` and your own pages in `app/app/pages/`. In a Nuxt project of your own, drop the first `app/`. See [Where things live](/getting-started/installation#where-things-live).
::
