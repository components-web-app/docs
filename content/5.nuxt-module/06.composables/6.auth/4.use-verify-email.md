`useVerifyEmail` completes the link in a verification email. `verifyEmail()` verifies a new account's address, and `confirmEmail()` confirms a change of address. Both read their values from the route params. The layer's `/verify-email/[username]/[token]` and `/confirm-new-email/[username]/[newEmail]/[token]` pages call them on mount.

```ts
const { verifyEmail, submitting, success, error } = useVerifyEmail()
onMounted(() => verifyEmail())
```

## Signature

```ts
useVerifyEmail()
```

It takes no parameters.

## Return Values

| Return | Type | Purpose |
|--------|------|---------|
| `verifyEmail` | `() => Promise<void>` | Reads `username` and `token` from the route params and calls [`cwa.auth.verifyEmail()`](/nuxt-module/cwa-api/auth#actions) |
| `confirmEmail` | `() => Promise<void>` | Reads `username`, `newEmail` and `token` and calls `cwa.auth.confirmEmail()` |
| `submitting` | `Ref<boolean>` | `true` while the request runs |
| `success` | `Ref<boolean>` | `true` once the address is verified or confirmed |
| `error` | `Ref<string \| undefined>` | A message for the visitor; see below |
| `getStringFromParam` | `(name: string) => string` | Reads one route param as a string, the first value if it is repeated, or `''` |

Use `verifyEmail()` on `/verify-email/[username]/[token]` and `confirmEmail()` on `/confirm-new-email/[username]/[newEmail]/[token]`. Call only the one that matches the page.

## Errors

- A missing route param sets `error` to "No username specified", "No token specified" or "No new email specified", and sends no request.
- A `404` sets it to "Request expired or has already been used."
- Anything else sets it to the API's message, its status text, or `Unexpected error`.

## Example

```vue
<!-- app/app/pages/verify-email/[username]/[token].vue -->
<script setup lang="ts">
definePageMeta({ cwa: { disabled: true } })
const { verifyEmail, submitting, success, error } = useVerifyEmail()
onMounted(() => verifyEmail())
</script>

<template>
  <p v-if="submitting">Verifying…</p>
  <p v-else-if="success">Your email address is verified.</p>
  <p v-else-if="error">{{ error }}</p>
</template>
```
