`useHtmlContent` makes the links in HTML from the API work like `<NuxtLink>`. After the component mounts, it replaces every `<a>` in a container with a `<CwaLink>`, so an internal link doesn't reload the page. It also returns `vCwaHtml`, a directive to use in place of `v-html`.

```ts
const container = ref<HTMLElement | null>(null)
const { vCwaHtml } = useHtmlContent(container, content)
```

```vue
<div ref="container" v-cwa-html="content" />
```

## Signature

```ts
useHtmlContent(
  container: Ref<HTMLElement | null>,
  html?: MaybeRefOrGetter<string | undefined>
): { vCwaHtml: Directive }
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `container` | `Ref<HTMLElement \| null>` | A template ref to the element that holds the HTML |
| `html` | `MaybeRefOrGetter<string \| undefined>` | The HTML source. Optional, but pass it: the links are converted again whenever it changes |

::callout{icon="i-heroicons-exclamation-triangle" color="warning"}
**Pass `html`.** With only the container, the conversion runs again only when the element changes. HTML that changes while the same element stays mounted, such as an inline edit or a Mercure update, keeps its raw `<a>` tags, and those links reload the page.
::

## Return Values

| Return | Type | Purpose |
|--------|------|---------|
| `vCwaHtml` | `Directive` | Renders HTML like `v-html`, without redrawing it during hydration. Destructure it in `<script setup>` and use it as `v-cwa-html`. It isn't registered globally |

## How Links Are Converted

- Each `<a>` with an `href` is replaced by a `<CwaLink>` mounted in a `<span>`. An `<a>` with no `href` is left alone.
- An absolute URL on the site's own hostname becomes a path, so it navigates client-side. Any other absolute URL stays external and opens in a new tab.
- An `href` that isn't a valid absolute URL and doesn't start with `/` is treated as a host, so `about` becomes `//about`. Write internal links as paths that start with `/`.
- Every attribute except `href` and `target` is copied to the link. Prefetching is off.
- The links are unmounted before each conversion and when the component unmounts.
- It runs in the browser only, after mount. The server renders the original `<a>` tags.
