`useCwaCollectionPagination` returns the page numbers to show in a numbered pagination control. It shows a sliding window of at most `maxPagesToDisplay` numbers around the current page. Use it in a pagination component next to a collection that uses [`withCollection()`](/nuxt-module/composables/component/use-cwa-component#withcollection).

```ts
import { useCwaCollectionPagination } from '#cwa/composables/cwa-collection-pagination'

const { pages } = useCwaCollectionPagination(props) // props: { currentPage, totalPages, maxPagesToDisplay }
```

## Signature

```ts
useCwaCollectionPagination(props: CwaPaginationProps): { pages: ComputedRef<number[]> }
```

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `props.currentPage` | `number` | The page being shown. Pass `pageModel` from `withCollection()` |
| `props.totalPages` | `number` | Pass `totalPages` from `withCollection()` |
| `props.maxPagesToDisplay` | `number` | The most page numbers to show. `0` means the default, `7` |

The composable reads `props` reactively, so pass a component's `defineProps()` result straight in. `CwaPaginationProps` and `CwaPaginationEmits` (`next`, `previous`, `change`) are exported from `#cwa/composables/cwa-collection-pagination` for that component.

## Return Values

| Return | Type | Purpose |
|--------|------|---------|
| `pages` | `ComputedRef<number[]>` | The page numbers to show, in order |

## How the Window Moves

- With fewer pages than `maxPagesToDisplay`, every page is listed.
- Otherwise the list starts at the current page and grows outwards, one page lower then one higher, until it holds `maxPagesToDisplay` numbers. Near the first or last page, the window shifts so it stays full.
- The numbers are always plain page numbers. There are no ellipsis markers, so add your own first and last links if you want them.
- With `totalPages` of `0`, the list is empty.
