The composable for CWA layout files. It returns the active layout resource and the raw `uiClassNames` stored on it.

```ts
const { layout } = useCwaLayout()
```

## Signature

```ts
useCwaLayout()
```

It takes no options.

## Return Values

| Return | Type | Purpose |
|--------|------|---------|
| `layout` | `ComputedRef<CwaCurrentResourceInterface \| undefined>` | The active layout resource. Its fields are on `.value?.data` |
| `uiClassNames` | `ComputedRef<string[] \| undefined>` | What the layout stores: one `style:<key>` entry for each style an admin picked |

## Example

```vue
<template>
  <div>
    <header>
      <CwaComponentGroup reference="nav" :location="$cwa.resources.layoutIri.value" />
    </header>
    <main><slot /></main>
  </div>
</template>

<script setup lang="ts">
defineCwaConfig({
  name: 'Primary Layout',
  styles: {
    'blue-bg': { label: 'Blue Background', classes: 'bg-blue-600' },
  },
})

const { layout } = useCwaLayout()
</script>
```

The layout's styles are declared with `defineCwaConfig` in the same file; see [Layouts › Configuring a Layout](/nuxt-module/building-your-ui/creating-layouts#configuring-a-layout). The root layout puts the picked styles' classes on your layout's root element, so you don't bind them.

## Styling an Inner Element

The classes always go on the root element. To style an inner element by the picked style, read the stored keys:

```vue
<template>
  <div>
    <main :class="{ 'max-w-none': wide }"><slot /></main>
  </div>
</template>

<script setup lang="ts">
const { uiClassNames } = useCwaLayout()
const wide = computed(() => !!uiClassNames.value?.includes('style:wide'))
</script>
```

## Accessing Layout Data

```ts
const { layout } = useCwaLayout()

// layout.value?.data holds the layout entity fields
const reference = computed(() => layout.value?.data?.reference)
```
