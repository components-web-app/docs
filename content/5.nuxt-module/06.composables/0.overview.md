---

Every composable the module provides is auto-imported. Pick one by what the file you are writing does.

## Decision Table

| You are writing | Use | Notes |
|-----------------|-----|-------|
| A layout (`app/app/cwa/layouts/`) | [`useCwaLayout`](/nuxt-module/composables/layout/use-cwa-layout) | Applies the admin's style classes to the layout's root |
| A display component (`app/app/cwa/components/<Name>/<Name>.vue`) | [`useCwaComponent`](/nuxt-module/composables/component/use-cwa-component) | **Recommended.** Add plugins for collections (`withCollection()`) and uploaded files (`withFile()`) |
| A display component that needs one file field without the plugin array | [`useCwaFileField`](/nuxt-module/composables/component/use-cwa-file-field) | The standalone form of `withFile()` |
| A component that only binds a resource, with no plugins | [`useCwaResource`](/nuxt-module/composables/component/use-cwa-resource) | Low level. `useCwaComponent` wraps it |
| Numbered pagination for a collection | [`useCwaCollectionPagination`](/nuxt-module/composables/component/use-cwa-collection-pagination) | Returns the page numbers to show |
| A form (a Symfony Form component) | [`useCwaForm`](/nuxt-module/composables/form/use-cwa-form) plus one [`useCwaFormInput`](/nuxt-module/composables/form/use-cwa-form-input) per field | [`useCwaFormRepeated`](/nuxt-module/composables/form/use-cwa-form-repeated) for a RepeatedType, [`useCwaFormCollection`](/nuxt-module/composables/form/use-cwa-form-collection) for a CollectionType |
| An admin tab (`app/app/cwa/components/<Name>/admin/`) | [`useCwaResourceManagerTab`](/nuxt-module/composables/admin-manager/use-cwa-resource-manager-tab) | Required in every tab |
| A field in an admin tab | [`useCwaResourceModel`](/nuxt-module/composables/admin-manager/use-cwa-resource-model) | [`useCwaResourceUpload`](/nuxt-module/composables/admin-manager/use-cwa-resource-upload) for a file field |
| Your own code that reacts when another admin saves a resource | [`onRemoteChange`](/nuxt-module/composables/admin-manager/on-remote-change) | Admins only; the module already shows the change |
| Your own events between admins on a resource, such as carets, or who else has it selected | [`useCwaRealtime`](/nuxt-module/composables/admin-manager/use-cwa-realtime) | Admins only, while co-editing is on |
| HTML from the API, with working internal links | [`useHtmlContent`](/nuxt-module/composables/utilities/use-html-content) | Also returns the `v-cwa-html` directive |
| A link to a resource's page | [`useCwaResourceRoute`](/nuxt-module/composables/utilities/use-cwa-resource-route) | `withCollection()` already returns it as `resolveResourceLink` |
| A sort, filter or search bound to the URL | [`useQueryBoundModel`](/nuxt-module/composables/utilities/use-query-bound-model) | |
| Your own API request that respects draft and published | [`useCwaResourceEndpoint`](/nuxt-module/composables/utilities/use-cwa-resource-endpoint) | |
| A custom login, password reset or email verification page | [`useLogin`](/nuxt-module/composables/auth/use-login), [`useForgotPassword`](/nuxt-module/composables/auth/use-forgot-password), [`useResetPassword`](/nuxt-module/composables/auth/use-reset-password), [`useVerifyEmail`](/nuxt-module/composables/auth/use-verify-email), [`useResendVerifyEmail`](/nuxt-module/composables/auth/use-resend-verify-email) | The layer's own auth pages use these |

Anything else goes through [`useCwa()`](/nuxt-module/cwa-api/overview), the service the composables are built on.

::callout{icon="i-heroicons-exclamation-triangle" color="warning"}
[`useCwaCollectionResource`](/nuxt-module/composables/component/use-cwa-collection-resource) is deprecated. Use `useCwaComponent(props, [withCollection()])` instead.
::
