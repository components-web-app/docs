A CWA site is built from three parts, each released on its own:

- **api-components-bundle**, the Symfony bundle, installed with Composer.
- **`@cwa/nuxt`**, the Nuxt module, installed from npm.
- **The template** (components-web-app), the project `create-cwa` generates. `create-cwa` has the same version as the template release it installs.

All three are in `2.0.0-alpha`. Pre-releases can change behaviour or configuration between versions, so update the three together and follow the upgrade notes of every release you skip over.

::callout{icon="i-heroicons-light-bulb"}
**The docs follow the development branches.** They describe the bundle's `main`, the module's `dev` and the template's `main`, which can be ahead of the last release. A recent change carries a short marker such as *Since bundle 2.0.0-alpha.16*, with a link to its upgrade notes.
::

## The module's minimum bundle

Some `@cwa/nuxt` releases need a newer bundle. Use at least this bundle version with each module version:

| `@cwa/nuxt` | api-components-bundle | Why |
|-------------|-----------------------|-----|
| `2.0.0-alpha.10` and later | `2.0.0-alpha.13` | Publishing sends `"publishedAt": "now"`, which older bundles reject |
| `2.0.0-alpha.9` | `2.0.0-alpha.11` | For the **Invalid files** report; everything else works with `2.0.0-alpha.9` |
| `2.0.0-alpha.8` | `2.0.0-alpha.9` | For the **Public without a route** toggle |
| `2.0.0-alpha.4` – `2.0.0-alpha.7` | `2.0.0-alpha.8` | Live updates use the Mercure 1.0 protocol, which a 0.x hub rejects |

The module's other requirements, such as its Nuxt version, are in [Module Setup → Requirements](/nuxt-module/module-setup#requirements).
