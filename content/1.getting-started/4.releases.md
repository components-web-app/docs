A CWA site is built from three parts, each released on its own:

- **api-components-bundle**, the Symfony bundle, installed with Composer.
- **`@cwa/nuxt`**, the Nuxt module, installed from npm.
- **The template** (components-web-app), the project `create-cwa` generates. `create-cwa` has the same version as the template release it installs.

CWA 2 is a prerelease (2.0.0-alpha), heading for a beta. It runs production sites; configuration can still change between releases, always with upgrade notes. Update the three together, and follow the upgrade notes of every release you skip over.

::callout{icon="i-heroicons-light-bulb"}
**The docs describe the current version.** They follow the bundle's `main`, the module's `dev` and the template's `main`, which can be ahead of the last release, and they don't say which release a feature arrived in. What changed in each release, and how to upgrade, is in its release notes below.
::

## Versions and support

- **SemVer from 2.0.0.** Until then every release is a prerelease, and any release can include a breaking change. Each one comes with an upgrade note in its release notes, so apply the notes of every release you skip.
- **The beta freezes the data model.** Before the beta, the template's migrations are squashed into one ([template #192](https://github.com/components-web-app/components-web-app/issues/192)). From the beta on, schema changes come as new migrations only, and breaking changes still come with upgrade notes.
- **The template and `create-cwa` share one version.** `create-cwa` X installs the template tagged `vX`, and `--ref` installs another branch or tag (see [Installation › 1. Scaffold your project](/getting-started/installation#_1-scaffold-your-project)).
- **npm's `latest` tag carries prereleases until 2.0.0.** `create-cwa` and `@cwa/nuxt` publish each prerelease as `latest`, so `pnpm create cwa` and `pnpm add @cwa/nuxt` install the newest release.
- **Only the latest prerelease is supported.** Older alphas get no fixes, security fixes included: upgrade to the latest release. Each repository's security policy says so and explains how to report a problem privately: the template's [SECURITY.md](https://github.com/components-web-app/components-web-app/blob/main/SECURITY.md), the API bundle's [SECURITY.md](https://github.com/components-web-app/api-components-bundle/blob/main/SECURITY.md) and the Nuxt module's [SECURITY.md](https://github.com/components-web-app/cwa-nuxt-module/blob/main/SECURITY.md).
- **Some bundle and module versions must be updated together.** The bundle each `@cwa/nuxt` release needs is in [Module Setup › Bundle versions](/nuxt-module/module-setup#bundle-versions).
