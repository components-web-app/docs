Components are the content editors place in your regions. Each component type is a PHP entity that holds its data, a Vue file that displays it, and an admin tab to edit it. The template's `Title` (`api/src/Entity/Title.php` and `app/app/cwa/components/Title/`) is a complete example. This guide builds a `Quote` component beside it and adds one to your `/landing` page.

::callout{icon="i-heroicons-photo"}
IMAGE: The `/landing` page with a Quote in its main region: the quote text in italics with the author below it
::

## Step 1: Scaffold the Vue component

The generator writes its file relative to the current directory, so run it **in `app/`**, the Nuxt project:

```bash
cd app
npx cwa make:component
```

Answer **Quote** for the name, **Basic** for the type, and yes to **publishable**. It writes `app/cwa/components/Quote/Quote.vue` inside `app/` — that's `app/app/cwa/components/Quote/Quote.vue` from the project root — and prints the command that creates the API entity.

::callout{icon="i-heroicons-exclamation-triangle" color="warning"}
Run from the project root, the generator writes to `app/cwa/components/`, which Nuxt never reads. Move the folder into `app/app/cwa/components/` if that happens.
::

::callout{icon="i-heroicons-photo"}
IMAGE: The `npx cwa make:component` prompts in a terminal — name, type and API behaviour questions — ending with the generated file path and the `php bin/console make:api-component Quote --publishable` command it prints
::

Open the generated file and fill in the template:

```vue
<template>
  <figure class="my-6 border-l-4 border-stone-400 pl-4">
    <blockquote class="text-xl italic">
      {{ resource?.data?.text || 'No quote yet' }}
    </blockquote>
    <figcaption
      v-if="resource?.data?.author"
      class="mt-2 text-sm"
    >
      — {{ resource.data.author }}
    </figcaption>
  </figure>
</template>

<script setup lang="ts">
import type { IriProp } from '#cwa/composables/cwa-resource'

const props = defineProps<IriProp>()
const { resource, exposeMeta } = useCwaComponent(props)
defineExpose(exposeMeta)
</script>
```

See [`cwa make:component`](/nuxt-module/building-your-ui/cwa-cli) for the full reference and the file/collection variants.

## Step 2: Create the API entity

The CLI prints the host form, `php bin/console make:api-component Quote --publishable`. PHP only runs in Docker, so run it through the `php` container from the project root:

```bash
docker compose exec php bin/console make:api-component Quote --publishable
```

That creates `api/src/Entity/Component/Quote.php` with no fields. Add the two the Vue file reads, and `mercure: true` so open pages receive edits live:

```php
<?php

namespace App\Entity\Component;

use ApiPlatform\Metadata\ApiResource;
use Doctrine\ORM\Mapping as ORM;
use Silverback\ApiComponentsBundle\Annotation as Silverback;
use Silverback\ApiComponentsBundle\Entity\Core\AbstractComponent;
use Silverback\ApiComponentsBundle\Entity\Utility\PublishableTrait;
use Symfony\Component\Validator\Constraints as Assert; // [!code focus]

#[Silverback\Publishable]
#[ApiResource(mercure: true)] // [!code focus]
#[ORM\Entity]
class Quote extends AbstractComponent
{
    use PublishableTrait;

    #[Assert\NotBlank(groups: ['Quote:published'])] // [!code focus]
    #[ORM\Column(type: 'text', nullable: true)] // [!code focus]
    public ?string $text = null; // [!code focus]

    #[ORM\Column(nullable: true)] // [!code focus]
    public ?string $author = null; // [!code focus]
}
```

The `Quote:published` group means a draft can be empty, but it can't be published without text. Then generate and run the migration:

```bash
docker compose exec php bin/console doctrine:migrations:diff
docker compose exec php bin/console doctrine:migrations:migrate
```

The migration lands in `api/migrations/`. Review it, and delete its `down()`: the template's migrations are [upward-only](/api/bundle-setup#database-setup). See [`make:api-component`](/api/console-commands#makeapi-component) for all available flags.

## Step 3: Add the admin tab

Create `app/app/cwa/components/Quote/admin/Quote.vue` — the editing form shown in the inline CMS:

::callout{icon="i-heroicons-photo"}
IMAGE: The manager panel open on a Quote component, showing the "Quote" admin tab with its text and author inputs
::

```vue
<template>
  <CwaUiFormLabelWrapper label="Quote">
    <CwaUiFormInput v-model="textModel.model.value" />
  </CwaUiFormLabelWrapper>
  <CwaUiFormLabelWrapper label="Author">
    <CwaUiFormInput v-model="authorModel.model.value" />
  </CwaUiFormLabelWrapper>
</template>

<script setup lang="ts">
import { useCwaResourceManagerTab, useCwaResourceModel } from '#imports'

const { exposeMeta, iri } = useCwaResourceManagerTab({ name: 'Quote' })
const textModel = useCwaResourceModel<string>(iri, 'text')
const authorModel = useCwaResourceModel<string>(iri, 'author')

defineExpose(exposeMeta)
</script>
```

## Step 4: Register in nuxt.config

Add an entry next to the template's `Title`:

```ts
// app/nuxt.config.ts
cwa: {
  resources: {
    Title: {
      // the template's existing entry
    },
    Quote: { // [!code focus]
      name: 'Quote', // [!code focus]
      description: '<p>A pull quote with an optional author.</p>', // [!code focus]
    }, // [!code focus]
  }
}
```

## Step 5: Add a Quote to the page

### Via the admin

Open `https://localhost/landing`, sign in and click **Edit**. Click **+** in the main region, choose **Quote**, and type in the tab. Changes save automatically. Click **Publish** to make it live.

::callout{icon="i-heroicons-video-camera"}
VIDEO: The full loop on `/landing` — entering edit mode, adding a Quote from the Add Component dialog, typing in the admin tab and watching the quote update live, then clicking Publish
::

### Via fixtures

In `api/src/DataFixtures/Parts/LandingScaffoldPart.php`, create a published Quote and add it to the page's `main` group:

```php
use App\Entity\Component\Quote; // [!code focus]

// ...

public function build(CwaFixtureBuilder $cwa, ScaffoldState $state): void
{
    $cwa->layout('landing', 'Landing');

    $quote = new Quote(); // [!code focus]
    $quote->text = 'Content is king.'; // [!code focus]
    $quote->author = 'Bill Gates'; // [!code focus]
    $quote->setPublishedAt(new \DateTime()); // [!code focus]

    $cwa->page('landing-page', 'TwoColumnPageTemplate', layout: 'landing', route: '/landing')
        ->title('Landing')
        ->group('main')->add($quote); // [!code focus]
}
```

The group name matches the `reference` in `TwoColumnPageTemplate.vue`. Load it from the project root:

```bash
docker compose exec php bin/console doctrine:fixtures:load --append
```

::callout{icon="i-heroicons-exclamation-triangle" color="warning"}
**`--append` never adds to a group that already exists.** The module creates a page's groups the first time a signed-in admin opens it, so if you've visited `/landing` signed in, or added a component there in the admin, the `main` group exists and the quote isn't added. Add it in the admin instead, or reload from empty with `doctrine:fixtures:load` (no `--append`). That deletes everything, editors' changes included, before the template's fixtures seed the site and the `admin` account again.
::
