This section is for anyone who wants to understand how CWA works before, or while, building with it: developers evaluating it, and developers who finished the guides. It explains ideas, with little code. The [Nuxt Module](/nuxt-module) and [API Bundle](/api) sections hold the reference.

If you only want enough to start building, [Key Ideas](/getting-started/key-ideas) has each term in a sentence or two. The [Glossary](/core-concepts/glossary) defines every CWA term in one place.

## Read in this order

| Page | What it explains |
|------|------------------|
| [How It All Works](/core-concepts/architecture) | What you get, what you write, and what happens on one request |
| [The Data Model](/core-concepts/the-data-model) | The resource types behind every page, and how they link |
| [Layouts & Pages](/core-concepts/layouts-and-pages) | The site shell, the pages inside it, and template pages |
| [Dynamic Pages](/core-concepts/dynamic-pages) | Page data: one template page for many records, such as blog articles |

| [The Admin Panel](/core-concepts/admin-panel) | How editors work on the page itself |
| [Caching](/core-concepts/caching) | Every cache between a visitor and the API, and what clears each one |
