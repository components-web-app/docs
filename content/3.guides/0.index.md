These guides are for developers building their first CWA site. Each one adds one thing to the same project, with the least code that works, and links to the reference for the rest.

Before you start, install a project (see [Installation](/getting-started/installation)) and read [Key Ideas](/getting-started/key-ideas). The guides use its terms.

::

## Follow them in order

| Guide | What you build |
|-------|----------------|
| [1. Your First Layout](/guides/your-first-layout) | A layout with your header and footer, and an editable banner |
| [2. Your First Page Template](/guides/your-first-page-template) | A page template with two component groups |
| [3. Your First Component](/guides/your-first-component) | A Quote component: the PHP entity, the Vue file and an admin tab |
| [4. Alternative UI Variants](/guides/alternative-ui-variants) | A second look for the same component, with style classes or a `ui/` file |
| [5. Your First Dynamic Page](/guides/your-first-dynamic-page) | News articles that share one template page, each with its own URL |

Each guide follows the same steps: create the file, register it in `nuxt.config.ts` if it needs it, then create the record in the admin or in fixtures.
